# 2026-09-07 發布範圍與狀態

## 目前版本：可保存、可送交網站發布驗收

本次版本包含聘僱表格與草稿保護、公告／行事操作、值日排版、年度盤點提醒、維修唯讀、手冊入口及資料寫入修補。新成員自助綁定維持暫停，既有綁定登入流程保留。

- 本機：73 項功能測試、17 項 Firestore 模擬器測試、正式建置通過。
- GitHub：草稿 PR #1 已存在；本輪新增 Validate website 工作流程，PR 會執行功能測試、固定版本模擬器測試與建置。
- Pages：部署工作依賴驗證工作成功，使用 Node 22 與 npm ci。main 更新才觸發正式網站部署；分支推送不部署。
- Firestore 與 GAS：Pages 工作流程不會部署這兩項服務。
- 正式 Google 登入及資料庫寫入尚未在這一輪驗證；既有線上規則也尚未取得可供比較的副本。

## 尚需另外完成的完整安全改版

1. 開通流程：管理員預先核准 Google 信箱或管理員審核申請，仍待使用者確認範圍。上一輪停用認領不是完整開通功能。
2. 身分與資料：既有 UID 重複檢查、UID 唯一對應、公開名冊／私密欄位分離及可重跑的資料遷移。
3. 值日：可信任週指派來源；現有欄位與順延驗證不能證明真正輪值歸屬。
4. 遷移後驗收：既有 Admin 與一般成員登入、解除綁定、學號轉移、盤點及值日操作。
5. Firebase 正式授權：2026-09-07 CLI login:list 確認尚無授權帳號；未自動登入、寫入正式資料或發布規則。

不得將候選 firestore.rules 直接部署來代替上述工作。網站更新與完整安全改版的完成狀態必須分別回報。

## 發布後核對

檢查 GitHub Actions 的驗證／Pages 工作結果與對應 commit，確認正式首頁、資產網址、路由與重新整理可載入。再由正式帳號驗證登入與一般成員權限。不要用 CI 模擬器通過宣稱正式權限或資料遷移已完成。
